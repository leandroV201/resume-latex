# Portfolio

Site pessoal em Angular (PT-BR / EN). Build, testes e deploy estão descritos no [README da raiz](../README.md).

```bash
npm ci
npm start          # http://localhost:4200
npm run test:ci
```

Os PDFs do currículo em `public/cv/` são gerados por `scripts/build-cv.sh portfolio/public/cv` e não vão para o Git.
